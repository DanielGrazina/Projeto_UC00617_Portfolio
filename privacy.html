Política de Privacidade — SecManagement

Última atualização: 13/02/2026

A aplicação SecManagement foi desenvolvida para fins académicos e destina-se à consulta de informação relacionada com gestão escolar/formação (ex.: horários, turmas, salas, cursos e perfis).

Dados que recolhemos

  • Dados de conta (ex.: email, nome e identificadores) apenas para autenticação e para apresentar a informação correta ao utilizador.
  • Tokens de autenticação (ex.: JWT) para manter a sessão ativa na aplicação.
  • Quando o utilizador utiliza Login com Google, recebemos do Google apenas as informações necessárias para autenticação (ex.: identificador e/ou email), conforme permitido pela conta do utilizador.

Como usamos os dados

Usamos os dados exclusivamente para:

  • autenticar o utilizador e permitir o acesso à aplicação;
  • apresentar conteúdos associados ao utilizador (ex.: dados do perfil e documentos);
  • melhorar a estabilidade e o funcionamento (ex.: mensagens de erro).

Partilha de dados

Não vendemos nem partilhamos dados pessoais com terceiros para fins comerciais. Os dados podem ser processados por serviços necessários ao funcionamento (ex.: Google Sign-In), apenas para autenticação.

Armazenamento e segurança

Os tokens de sessão podem ser guardados localmente no dispositivo para manter o login. Implementamos medidas razoáveis de segurança, mas nenhum sistema é 100% infalível.

Retenção

Os dados são mantidos apenas pelo tempo necessário para a finalidade da aplicação e de acordo com as regras do sistema (backend). O utilizador pode solicitar a remoção/limpeza da conta conforme indicado abaixo.
